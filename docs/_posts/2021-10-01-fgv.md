This application was developed for a math competition for high-school students. The goal was to demonstrate a high-school math concept in an interesting manner, so I decided to create an application that helps high-school student understand basic function transformations, by playing around with them and then doing practice exercises.

![Image](/assets/images/fgv/app.png)

Most of my time was spent on the custom rendering engine that I wrote in Lua using the LÖVE2D framework.
While getting started using this framework is really easy and it is much less buggy and slow than Python Pygame, Lua is not really for big projects.
I also tried to develop the application for mobile, but I did not end up submitting it because the control mechanics did not end up great.

Considering that this was the first real project that I have done, I am proud of the outcome and the third place I ended up receiving in the competition.
