This program was written as a homework project for my Basics of Programming 1 course. The code is not optimized nor pretty since it had to meet strict deadlines.
I first wrote a prototype in Python to test my ideas.
Both the Python prototype and the final C code can be found on my GitHub.

The following specification assumes no knowledge of the Pascal language and refers to the C alternative for every concept.

#### Blocks

The blocks in Pascal start with the keyword begin and end with the keyword end. if it is the main function and with the keyword end; for any other block. If there is only one statement the opening and closing keywords can be omitted just like in C.

#### Comments

Single-line comments in Pascal use the same character as in C. Multi-line comments use { and } instead of /* and */.

```pascal
begin
    // This is a single-line comment.
    {
        This is multi-line
        comment.
    }
end.
```

```c
int main() {
    // This is a single-line comment.
    /*
        This is a multi-line
        comment.
    */
    return 0;
}
```

#### Variables
In Pascal variables are declared in variable sections. \
These variable sections can be in the global scope or they can belong to a function or a prodecure. (Will be shown later) \
Variables are later assigned a value with the := operator. \
The following conversions have to be made:

1. integer -> int
2. real -> double
3. array[from..to] of type -> type name[to-from+1]
```pascal
var
    n : integer;
    pi : real;
    letter : char;
    arr : array[1..10] of integer;
begin
    n := 1;
    pi := 3.14;
    letter := 'A';
    arr[0] := 1;
end.
```
```c
int n;
double pi;
char letter;
int arr[10];
int main() {
    n = 1;
    pi = 3.14;
    letter = 'A';
    arr[0] = 1;
    return 0;
}
```

#### Constants
Like variables, constants are also declared and assigned in a separate constant section. \
In Pascal constants don't have defined types so the converter has to detect the type before converting to C.
```pascal
const
    n = 1;
    pi = 3.14;
    letter = 'A';
```
```c
const int n = 1;
const double pi = 3.14;
const char letter = 'A';
```

#### Type section
Records (which are the Pascal analogs of structs in C) have to be defined in the type section.
```pascal
type
Book = record
    id : integer;
    title: array [1..50] of char;
    author: array [1..50] of char;
    subject: array [1..100] of char;
end;
```
```c
typedef struct {
    int id;
    char title[50];
    char author[50];
    char subject[50];
} Book;
```

#### Input/output using the standard IO
The Pascal IO functions create the formatted string for you, so the converter has to use the type information of the variables to recreate the same functionality in C.
```pascal
var
    x : integer;
    line : array[1..100] of char;
begin
    read(x);
    readln(line);
    writeln(x);
    write(line);
end.
```
```c
#include <stdio.h>
int x;
char line[100];
int main() {
    scanf("%d", &x);
    fgets(line, sizeof(line), stdin);
    printf("%d\n", x);
    printf("%s", line);
    return 0;
}
```

#### Conditional statements
In Pascal conditional statements work similarly to C, but the else if statement does not exist. The parentheses for the logical expression can be omitted in Pascal, so the converter has to insert it, if it is missing. \
Logical operations have different symbols which have to be converted into their respective alternatives in C.
The following conversions have to be made:

1. equals: = -> ==
2. not equal: <> -> !=
3. logical and: and -> && 
4. logical or: or -> ||
5. not: not -> !
6. xor: xor -> ^
```pascal
var
    x : integer;
begin
    x := 1;
    if (x > 0) then
        x := x - 1
    else
        x := x + 1;
end.
```
```c
int x;
int main() {
    x = 1;
    if (x > 0)
        x = x - 1;
    else
        x = x + 1;
    return 0;
}
```

#### Loops
The while loop in Pascal functions the same way as in C.
```pascal
var
    i : integer;
begin
    i := 0;
    while (i < 100) do
    begin
        write(i, ' ');
        i := i + 1;
    end;
end.
```
```c
#include <stdio.h>
int i;
int main() {
    i = 0;
    while (i < 100) {
        printf("%d ", i);
        i = i + 1;
    }
    return 0;
}
```
The for loop in Pascal has the same functionality as in C, but it uses different keywords. The to keyword means that it increments the iterator variable until it reaches the desired value (inclusive). If you want to decrement the iterator variable you have to use the downto keyword.
```pascal
var
    i : integer;
begin
    for i := 0 to 100 do
        write(i, ' ');
end.
```
```c
#include <stdio.h>
int i;
int main() {
    for (i = 0; i <= 100; i++)
        printf("%d ", i);
    return 0;
}
```

#### Procedures
Pascal procedures, which are the alternatives of void functions in C, can have arguments, listed the same way as in a var section, and a var section for the local variables. If a procedure does not have arguments it can be called without parentheses.
```pascal
procedure write_as_meters(feet, inches : integer);
var
    meters : real;
begin
    inches := 12 * feet + inches;
    meters := inches / 39.39;
    write(meters);
    writeln;
end;
begin
    write_as_meters(5, 10);
end.
```
```c
#include <stdio.h>
void write_as_meters(int feet, int inches) {
	double meters;
	inches = 12 * feet + inches;
	meters = inches / 39.39;
	printf("%lf", meters);
    printf("\n");
}
int main() {
	write_as_meters(5, 10);
	return 0;
}
```

#### Functions
The main difference between Pascal and C functions is that instead of having a return keyword Pascal functions assign the return value to the function's name. Their declaration is similar to a procedure's, but they also have a return type.
```pascal
function max(x, y : integer) : integer;
begin
    if (x > y) then 
        max := x
    else
        max := y;
end;
var
    a, b, c : integer;
begin
    write('Enter two numbers : ');
    read(a, b);
    c := max(a, b);
    writeln('Maximum = ', c);
end.
```
```c
#include <stdio.h>
int max(int x, int y) {
	if (x > y)
		return x;
	else
		return y;
}
int a;
int b;
int c;
int main() {
	printf("Enter two numbers : ");
	scanf("%d%d", &a, &b);
	c = max(a, b);
	printf("Maximum = %d\n", c);
	return 0;
}
```

#### Built-in functions
The following are the requested built-in functions.
```pascal
var
    x, n : integer;
    a, b : char;
begin
    x := 2;
    x := succ(x);
    x := pred(x);
    c := 'a';
    n := ord(c);
    a := chr(n);
    x := sqr(x);
    x := sqrt(x);
end.
```
```c
#include <math.h>
int x;
int n;
char a;
char b;
int main() {
    x = 2;
    x = x + 1;
    x = x - 1;
    c = 'a';
    n = (int)c;
    a = (char)n;
    x = x*x;
    x = sqrt(x);
    return 0;
}
```
