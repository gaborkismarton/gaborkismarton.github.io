My friend and I participated in the Code In - Way Out: Hack the Maze Online Hackathon hosted by Deutsche Telekom IT Solutions. We first designed our data structures and algorithms in Python and then ported the project to C to achieve the desired performance. Our submission perfectly solved all levels of mazes in the Docker test suite provided by the organizers.

![Image](/assets/images/codein/maze.png)

For the first level we had to solve a simple 15x15 maze with the shortest possible distance.

![Image](/assets/images/codein/lvl1.png)

The second level introduced traps, which would teleport you back to the starting position when stepped on and they would disappear the next time you entered the maze.

![Image](/assets/images/codein/lvl2.png)

In the third level the maze was split into 9 5x5 districts which could be rotated before moving into them, making it even more difficult to find the shortest path through the maze.

![Image](/assets/images/codein/lvl3.png)
![Image](/assets/images/codein/lvl3-rotated.png)

Our solution utilizes the well-known Dijkstra's algorithm, but it is ran on a custom d-ary heap implementation that stores our so called Cross objects.

We learned a lot about the different implementations of Dijkstra's algorithm and d-ary heaps from this video: 

{% youtube "https://www.youtube.com/watch?v=pSqmAO-m7Lk" %}

The Python codes, the C code and the Docker environment used for testing is available on my GitHub.
